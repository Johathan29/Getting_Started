# Base de datos 
    Una base de datos es un conjunto organizado y estructurado de información que se almacena de forma electrónica para permitir su fácil consulta, actualización y administración.

¿Qué contienen las bases de datos?

Pueden almacenar casi cualquier tipo de información digital, dividida habitualmente en:
• Datos de texto y números: Nombres, direcciones, precios, cantidades, códigos o fechas.
• Archivos multimedia: Imágenes, videos, audios o documentos (que a menudo se guardan como rutas o metadatos de ubicación, mientras el archivo físico reside en un servidor).
• Relaciones y metadatos: Conexiones entre usuarios, historial de transacciones, registros de actividad y configuraciones del sistema.

## Principales elementos

• Tablas, filas y columnas: En los sistemas tradicionales, los datos se organizan en filas (registros) y columnas (campos).
• Sistema de Gestión de Bases de Datos (DBMS): El software que permite leer, escribir, modificar y proteger los datos (por ejemplo, MySQL, PostgreSQL o MongoDB).
• Lenguaje de consulta: Generalmente SQL para bases de datos relacionales o estructuras flexibles (documentos, grafos o clave-valor) para bases de datos NoSQL.
